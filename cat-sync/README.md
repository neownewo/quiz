# 貓貓腦迴路（題庫 JSON V4）

- `cat-sync/questions.json`：正式遊戲唯一題庫來源，共 150 題，全部四選一。
- `cat-sync/review-records.json`：本輪審核狀態及被刪除題目的封存資料，不會載入遊戲。
- `question-review.html`：獨立離線題庫審核頁，可直接雙擊開啟。
- 房號＋題目 ID＋題庫版本用固定演算法為第 41、56 題搭配成員；房主廣播完整選項與摘要供加入者驗證。
- 不使用場次 ID，同一局題目不重複；新房號可產生不同選項。
- 正式遊戲仍需 Vercel `/api/cat-config` 與 Supabase 環境變數。
- 修改題庫 JSON 後重新部署；若改動固定亂數規則或題庫結構，請同步更新 `version`。
- 第 21 題為使用者提供的金句辨誤題，尚未核對原作台詞，作為默契選擇題而非權威正誤測驗。
